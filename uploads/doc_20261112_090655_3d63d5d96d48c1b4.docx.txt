PRACTICAL – BUZZER INTERFACING WITH RASPBERRY PI

1. Aim

To interface a buzzer with Raspberry Pi and write a Python program to turn the buzzer ON and OFF continuously with a delay of one second.

2. Components Required

Raspberry Pi 3 B+

Buzzer

Jumper wires

Breadboard

Power supply

3. Connection

Raspberry Pi Pin

 | Device Connection

 | 
GPIO20 (CN03)

 | Buzzer IN (CN25)

 | 
4. Theory

A buzzer is an electronic output device used to produce sound. It is commonly used in alarm systems, warning systems, timers, and IoT applications.

In this practical, the buzzer is connected to GPIO20 of the Raspberry Pi. The GPIO pin is configured as an output pin.

When GPIO20 is set to HIGH, the buzzer turns ON. When GPIO20 is set to LOW, the buzzer turns OFF.

A delay of one second is provided between the ON and OFF states using the time.sleep() function.

5. Algorithm

Start the program.

Import the GPIO and time libraries.

Set GPIO numbering mode to BCM.

Disable GPIO warning messages.

Configure GPIO20 as an output pin.

Turn the buzzer ON.

Wait for one second.

Turn the buzzer OFF.

Wait for one second.

Repeat the process continuously.

6. Program

import RPi.GPIO as GPIO

import time

GPIO.setmode(GPIO.BCM)

GPIO.setwarnings(False)

GPIO.setup(20, GPIO.OUT)

while True:

    print("BUZZER ON")

    GPIO.output(20, GPIO.HIGH)

    time.sleep(1)

    print("BUZZER OFF")

    GPIO.output(20, GPIO.LOW)

    time.sleep(1)

7. Program Explanation

import RPi.GPIO as GPIO imports the Raspberry Pi GPIO library for controlling GPIO pins.

import time imports the time library for providing delays.

GPIO.setmode(GPIO.BCM) selects BCM GPIO numbering.

GPIO.setwarnings(False) disables GPIO warning messages.

GPIO.setup(20, GPIO.OUT) configures GPIO20 as an output pin.

GPIO.output(20, GPIO.HIGH) sends a HIGH signal to GPIO20 and turns the buzzer ON.

time.sleep(1) provides a delay of one second.

GPIO.output(20, GPIO.LOW) sends a LOW signal to GPIO20 and turns the buzzer OFF.

while True: continuously repeats the ON and OFF operation.

9. Result

The buzzer was successfully interfaced with the Raspberry Pi using GPIO20, and it was turned ON and OFF continuously with a delay of one second.
